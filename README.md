# Two Black Cats — Morty & Negrita

> *Un cuento cinematográfico sobre dos sombras Bombay que aprendieron a habitar la casa antes que nosotros.*

---

## Español

Sitio web personal dedicado a **Morty** y **Negrita**, dos gatos Bombay de ojos ámbar. Una sola página de desplazamiento con scroll cinematográfico, animaciones de revelado, parallax y un efecto de capas apiladas.

### Ejecutar en local

Abre `index.html` directamente en el navegador. Sin servidor, sin instalaciones.

### Estructura

```
/
├── index.html          # Página principal
└── src/
    ├── styles.css      # Todos los estilos y tokens de diseño
    ├── main.js         # Interacciones: cursor, scroll reveal, parallax…
    ├── images/         # Fotos de archivo
    ├── uploads/        # Fotos propias de las gatas
    └── design-images/  # Retratos generados para el diseño
```

### Tecnología

HTML, CSS y JavaScript puros — sin dependencias, sin framework, sin paso de compilación. Tipografías desde Google Fonts: **Cormorant Garamond**, **Archivo** y **DM Mono**.

## English

A personal website dedicated to **Morty** and **Negrita**, two amber-eyed Bombay cats. A single scroll-based page with cinematic reveal animations, parallax, and a stacked-layer effect.

### Running locally

Open `index.html` directly in a browser. No server, no installs.

### Structure

```
/
├── index.html          # Main page
└── src/
    ├── styles.css      # All styles and design tokens
    ├── main.js         # Interactions: cursor, scroll reveal, parallax…
    ├── images/         # Archive photos
    ├── uploads/        # Personal photos of the cats
    └── design-images/  # Portraits generated for the design
```

### Stack

Pure HTML, CSS and JavaScript — no dependencies, no framework, no build step. Typefaces from Google Fonts: **Cormorant Garamond**, **Archivo** and **DM Mono**.
